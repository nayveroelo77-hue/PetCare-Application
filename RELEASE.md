## 🚀 PetCare Application v1.1.0

This is the v1.1.0 release of the **PetCare Application** — a small maintenance update including branding and UI polish.

### 📥 Download

You can download the Android build here:

- **[Download PetCare-Signed.apk (MediaFire)](https://www.mediafire.com/file/fbn8nkcvb6a6de8/com.companyname.petcare-Signed.apk/file)**

### 🛠 Installation (Android)

1. Download the APK file to your Android device.
2. Open the file.
3. If prompted, go to your settings and enable **Installation from Unknown Sources** for the installer.
4. Follow the on-screen prompts to complete installation.

---

### 🧾 What's new in v1.1.0

- Updated app branding: swapped the primary splash and app icon to the PetCare orange theme.
- Added a "View Details" action in client appointments to see appointment notes and metadata.
- Minor UI polish and bug fixes across the client pet and appointments pages.
